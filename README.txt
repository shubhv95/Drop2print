Drop2Print - flat GitHub upload package

Upload ALL files in this folder directly to the ROOT of your existing GitHub Pages repository.
There are NO folders in this package.

Files:
- index.html: updated site, pink/navy brand styling, logo, SEO metadata and PWA links
- drop2print-logo.png: website logo
- favicon.ico, favicon-16x16.png, favicon-32x32.png, favicon-48x48.png: browser favicons
- apple-touch-icon.png: Apple home-screen icon
- icon-192.png, icon-512.png: installable web app icons
- manifest.json: installable web app configuration
- sw.js: service worker for app-shell caching

Important:
- Upload the FILES themselves, not the enclosing ZIP.
- Keep canonical URL as https://drop2print.work.gd/ unless your domain changes.
- SEO metadata does not guarantee Google ranking.
- PDF support currently relies on PDF.js from a CDN, so the full app is not completely offline.
